# ☕ Coffee Shop Sales Dashboard

An interactive **Excel Dashboard** built to analyze and visualize sales performance of a coffee shop.  
This dashboard helps track **total sales, customer footfall, product performance, and store comparisons** — all in one view.

---

## 📸 Dashboard Preview
![Coffee Dashboard](Coffee%20Dashboard.jpg)

---

## 📊 Project Overview

This project presents a clean and dynamic Excel dashboard that summarizes:
- 💰 **Total Sales:** `$397,431.74`
- 👣 **Total Footfall:** `84,676`
- 🧾 **Average Bill:** `$4.86`
- ☕ **Average Orders per Customer:** `1.44`

---

## 🧠 Key Insights

### ⏰ Sales by Hour
- Most active hours: **8 AM – 10 AM**
- Sales start to decline after **10 AM**

### 🍰 Category Performance
- **Coffee:** 39% of total sales  
- **Flavours:** 28%  
- **Bakery Items:** 12%

### 🧍‍♂️ Size Preferences
- **Regular (31%)** and **Large (30%)** are most sold sizes.

### 📍 Store Location Performance
| Store Location     | Total Sales ($) | Footfall |
|--------------------|----------------:|----------:|
| Astoria            | 152,501.49      | 33,211    |
| Hell’s Kitchen     | 156,091.59      | 33,573    |
| Lower Manhattan    | 151,813.75      | 31,491    |

### ☕ Top 5 Products
1. Barista Espresso  
2. Brewed Black Tea  
3. Brewed Chai Tea  
4. Gourmet Brewed Coffee  
5. Hot Chocolate  

### 📅 Orders by Weekday
- **Thursday:** Most orders (15,040)  
- **Wednesday:** Fewest orders (12,986)
